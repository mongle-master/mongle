결은 일기·관계 기록 도메인을 위한 디자인 시스템이다. ElevenLabs 마케팅 서피스의 편집 잡지적 절제 — 오프화이트 캔버스, 따뜻한 근검정 잉크, weight 300 세리프 디스플레이, 파스텔 대기 orb — 에서 값이 아니라 규칙을 추출해 기록과 회고의 화면 문법으로 재배치했다. 색은 감정에만 살고, 크롬은 조용하다.

토큰 아키텍처

3계층 — 그러나 성장은 2계층부터

정본은 src/styles/globals.css 하나다. 앱과 Storybook과 이 문서가 모두 이 파일을 소비한다.

TIER 1 · PRIMITIVES

테마 불변 원시 팔레트

따뜻한 중성 램프 14 + 파스텔 orb 5 + 야간 orb 5 + 상태색. :root에 한 번 정의되고 테마를 타지 않는다.

TIER 2 · SEMANTIC

역할 토큰 — 리매핑 유일 장소

--background, --primary, --emotion-*… 전부 var(--primitive) 참조. Paper/Night 전환은 이 블록만 교체한다.

TIER 3 · COMPONENT

별도 계층 없음

CVA variant와 data-slot 셀렉터가 Tier 2를 직접 소비한다. 수백 개 component 토큰은 우리 규모에 과잉 (YAGNI).

네이밍

역할로 짓고, 쌍으로 다닌다

규칙 예
배경 역할에는 항상 글자 쌍 --card / --card-foreground, --primary / --primary-foreground
원시값은 램프 번호, 역할값은 의미 --neutral-800 → --primary
감정은 영어 낱말 + 한글 라벨 --emotion-calm = 고요, --emotion-dear = 소중
컴포넌트는 data-slot, variant는 data-* [data-slot="button"], [data-emotion="warm"]

색상

회색조 규율, 파스텔은 아낀다

무채색이 팔레트의 70%다. 유일한 색채 전압인 파스텔 orb 5색은 감정의 대기 표현으로만 쓴다 — 버튼 칠, 텍스트, 컴포넌트 배경 금지.
