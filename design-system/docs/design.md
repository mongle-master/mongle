# 결 (Gyeol) — 디자인 언어 원칙

> 단계 C (playbook §3). ElevenLabs의 시각 언어를 일기·관계 기록 도메인에 맞게
> 번역한 규칙 문서다. 값은 토큰 CSS(`src/styles/globals.css`)가 정본이고, 이
> 문서는 **값이 바뀌어도 남는 규칙**을 정의한다. 이후 모든 코드리뷰의 판정 기준.

## 방향

결은 종이 일기장의 물성을 디지털로 옮긴 언어다. ElevenLabs 마케팅 서피스의
편집 잡지적 절제 — 오프화이트 캔버스, 따뜻한 근검정 잉크, weight 300 세리프
디스플레이, 파스텔 대기 orb — 를 가져와 기록·회고 화면의 문법으로 재배치한다.

> "ElevenLabs의 절제를 빌려왔다 — 회색조 규율 위에 서고, 파스텔은 아낄수록
> 강해진다. 색은 감정에 살고, 크롬은 조용하다."

- 기본 캔버스: `#f5f5f5` (따뜻한 오프화이트), 카드: 순백
- 기본 잉크: `#0c0a09`, 본문: `#4e4e4e`, 보조: `#777169`
- 유일한 기능 강조: 잉크 자체 — 채도 높은 브랜드 액션 색을 만들지 않는다
- 디스플레이: 세리프 weight 300 고정 · 본문: 산세리프(Pretendard) 400/500
- 기록 본문: 손글씨 서체 slot — 종이에 쓰는 인상
- 버튼·배지: pill, 카드: 16px, 입력: 8px
- 섹션 리듬: 96px, 카드 사이: 16~24px

## 법적·윤리적 경계

> ElevenLabs의 로고, 상표, 전용 서체(Waldenburg)와 음성 서비스 구조(IA)는
> 복제하지 않는다. 가져가는 것은 색 관계, 밀도, 위계, 모션의 원리뿐이다.

- Waldenburg를 번들하거나 임베드하지 않는다. 대체 서체(라틴: Cormorant Garamond
  300, 한글: Noto Serif KR 300)를 쓰고, "디스플레이 세리프 weight 300"이라는
  규칙만 승계한다.
- gradient orb 5색은 일반 파스텔 톤이라 값 자체는 차용 가능하나, ElevenLabs
  히어로의 구도·사진 스타일은 따라 하지 않는다.

## DO / DON'T

### DO

- 잉크 pill은 오직 **주요 액션 하나**에만. 한 화면에 잉크 pill이 둘이면 하나를
  outline으로 내린다.
- 디스플레이는 항상 weight 300. 크게 쓸수록 letter-spacing을 조인다.
- 파스텔 orb는 **감정의 대기**로만 — 감정 선택·기록 카드 배경 블룸·회고 무드.
- 기록 본문은 손글씨 서체, UI 텍스트는 산세리프. 두 서체의 역할을 섞지 않는다.
- 헤어라인(1px)으로 영역을 나누고, 카드는 순백 + 부드러운 그림자 한 단계만.
- 다크 테마는 역할 반전 — 모든 색은 semantic 토큰을 타고 자동으로 뒤집혀야 한다.

### DON'T

- 채도 높은 브랜드 액션 색을 새로 만들지 않는다 (초록·파랑 CTA 금지).
- 디스플레이를 볼드하지 않는다 — 300이 무너지면 편집 잡지에서 소비재 마케팅으로
  이동한다.
- orb 그라디언트를 버튼 칠·텍스트 색·컴포넌트 배경으로 쓰지 않는다. 대기 전용.
- CTA에 각진 모서리(`rounded-none`)를 쓰지 않는다. pill이 브랜드 버튼이다.
- 본문 산세리프를 300으로 내리지 않는다 — 가독성 하한 400.
- 카드 안에 카드를 넣지 않는다. 겹침 대신 헤어라인과 명도차.
- 감정 색을 즉흥으로 추가하지 않는다 — 5가족(고요·따뜻·사색·맑음·소중) 안에서
  명도만 조절한다.

## 도메인 확장 지점

레퍼런스에 없는 일기 도메인 요소를 레퍼런스의 문법 안에서 정의한다.

| 요소 | 레퍼런스 문법에서의 정의 |
|---|---|
| 감정 orb 5가족 | gradient-* 5토큰의 **유일한 의미 사용처**. 고요=mint, 따뜻=peach, 사색=lavender, 맑음=sky, 소중=rose. orb는 `currentColor`가 아닌 고정 파스텔 — 그러나 컴포넌트는 크기·흐림만 받아 어떤 화면에도 이식 가능 |
| 감정 스케일 | Daylio식 5단계. 각 단계는 orb 색의 명도 단계(연한→진한)로 표현하고 색 이름+라벨을 반드시 동반한다 (색만으로 구분 금지) |
| 편지지 (LetterPaper) | 괘선 SVG 패턴을 배경으로 가진 기록 작성 표면. 라이트: 검은 괘선 7% / 다크: 흰 괘선 10% — 테마별 별도 정의 (배경 이미지라 currentColor 불가) |
| 손글씨 slot | `--font-hand`. 기록 본문·회고 인용에만. UI 라벨에 쓰면 역할 오염 |
| On This Day 카드 | 1년 전 오늘 회고. eyebrow(대문자 캡션) + 세리프 인용 + orb 대기 — 레퍼런스의 testimonial-card 문법 재사용 |
| 사람 chip | voice-row/voice-icon-circular 문법 재사용 — 32px 원형 plate(surface-strong) + 이름 |
| Year in Pixels | 감정 orb 5색을 점 하나로 찍는 연간 그리드. 색은 orb 팔레트 한정 — "시리즈마다 새 색 차트" 금지 규칙의 준수 사례 |

## 토큰 정본

실제 값의 정본은 `src/styles/globals.css`다. Storybook과 쇼케이스 HTML이 이 파일을
직접 import(또는 인라인)한다.

| 토큰군 | 용도 |
|---|---|
| `--background`, `--foreground` | 오프화이트 캔버스와 근검정 잉크 |
| `--card`, `--popover` | 순백 카드와 오버레이 표면 |
| `--primary` | 주요 액션 = 잉크 pill (라이트: stone-800 / 다크: paper-white 반전) |
| `--secondary`, `--muted`, `--accent` | 보조 조작·hover·비활성 표면 |
| `--destructive`, `--warning`, `--success` | 상태색 — 레퍼런스에 없던 warning을 도메인 확장으로 추가 |
| `--emotion-*` (5) | 감정 orb 파스텔 — 대기 전용 (양 테마 모두 파스텔) |
| `--emotion-*-text` (5) | 감정의 "읽기" 계층 — 라이트: AA 전면 변형(≥4.5:1) / 다크: 파스텔(≥10:1). 칩 글자·라벨용 |
| `--favorite` | 즐겨찾기 별 전용 앰버 — 경고(--warning)와 역할을 분리 (ui-audit 8-4) |
| `--hairline-*` (3) | 1px 구분선 3단계 |
| `--radius-*` | 입력 8 / 카드 16 / 대기 카드 24 / pill 9999 |
| `--elevation-1..4` | 그림자 4단계, 라이트/다크 각각 정의 — 소비는 `shadow-e1..e4` 유틸리티로 |
| `--font-display`, `--font-sans`, `--font-hand` | 세리프 300 / 산세리프 / 손글씨 |

폰트 로딩은 토큰에 포함하지 않는다 — 소비자가 제공한다 (앱: @fontsource 번들,
Storybook·쇼케이스: `.storybook/fonts.css`의 CDN).

브랜드 주입 훅: `--brand: var(--primary)`를 루트에 두고, 테마·텐던트 브랜딩이
필요한 서브트리에서만 재할당한다 (전역 토큰 덮어쓰기 금지).

## 컴포넌트 원칙

1. shadcn 구조의 소유형 소스를 쓴다 — npm 의존이 아니라 복사해 소유한 코드.
2. Radix headless 프리미티브 위에 스타일만 우리 토큰으로 입힌다. 접근성(ARIA·
   키보드)을 직접 발명하지 않는다.
3. 열거형 variant는 CVA, 모든 루트 요소에 `data-slot` 마킹.
4. 이미 있는 프리미티브(Button, Dialog, Input, Tabs…)를 도메인 컴포넌트가 다시
   만들지 않는다. 도메인 컴포넌트는 프리미티브의 **조합**이다.
5. 모든 입력은 label + 오류 문구 + 키보드 포커스를 제공한다. 색만으로 상태를
   구분하지 않는다 (감정 색은 반드시 라벨 동반).
6. compound component는 실제 공유 상태가 있을 때만 context를 도입하고,
   `Root/Header/Content/Footer` 역할 이름을 쓴다.

## 화면 밀도

- 페이지 제목과 주요 액션은 한 줄 헤더로 묶는다.
- 간격은 4px 기반 9단계 토큰만. 임의 px 대괄호 값을 만들지 않는다.
- 목록 행 기본 높이 48px+, 주요 버튼 44px+.
- 섹션 사이 96px, 카드 사이 16~24px — 넓은 여백이 일기의 호흡이다.
- 데이터 표는 모바일에서 카드로 재발명하지 않고 가로 스크롤.

## 상태와 애니메이션

- 전이는 120~200ms의 색·opacity·transform만.
- orb 대기는 느린 float(6~10s)만 허용 — 빠른 펄스·반짝임 금지. 일기는 조용하다.
- 새 기록 저장 같은 단일 이벤트만 짧게 강조하고 반복 애니메이션을 남기지 않는다.
- `prefers-reduced-motion`에서 이동·float 애니메이션 전부 제거.
- 폼 오류는 필드 바로 옆에, 전역 피드백은 토스트로.

## Storybook과 테스트

- 이 패키지는 앱과 독립된 Storybook을 가진다. 앱 경로를 읽지 않는다.
- 프리미티브는 시각 variant + 키보드/포커스 상태 story.
- 도메인 컴포넌트는 정상·빈 상태·긴 텍스트·모바일 폭 story.
- Testing Library는 role/label 기반의 관찰 가능한 행동만 검증한다.
- Story DOM 스냅샷과 비주얼 리그레션은 사용하지 않는다 (playbook F 정책).
