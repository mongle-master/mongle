# 디자인 시스템 결(Gyeol)

UX 방향성 프로토타입 A(관계 궤도, 2026-07-29)의 디자인 언어를 앱 전역으로
채택한 정본. 정수는 **편집적 절제** — 잉크 중성 램프와 종이 표면 위에
따뜻한 시그널 한 색만 아껴 쓴다. 구현은 `src/styles.css`의 `:root`/`.dark`가
단일 출처이고, 이 문서는 그 계약의 요약이다.

## 색상

| 토큰                   | 라이트              | 다크           | 쓰임                     |
| ---------------------- | ------------------- | -------------- | ------------------------ |
| `foreground`/`primary` | `#26262B` 잉크      | `#F7F7F8`      | 본문·버튼 채움·활성      |
| `muted-foreground`     | `#8E8E93`           | `#98989D` 계열 | 보조 텍스트              |
| `muted-soft`           | `#B0B0B5`           | 더 어두운 값   | 링 라벨·환기 문구        |
| `card`/`background`    | 종이 `#FFFFFF`      | `#1C1C20` 계열 | 표면                     |
| `muted`/`secondary`    | 표면 `#F7F7F8`      | `#232327` 계열 | 스탯 타일·칩 바닥        |
| `border`               | 결선 `#EBEBEC`      | white 10%      | 머리선                   |
| `input`                | 결선 진한 `#DDDDDF` | white 15%      | 입력 테두리·그랩버       |
| `warm`                 | `#E06A2B`           | 더 밝은 값     | 아이브로우·환기 안내에만 |

램프는 hue 286(약간의 보라 기운)으로 순수 회색보다 종이에 가깝다.
감정·관계태그 색은 per-chip hex 동적 칩(고정 enum 없음)을 유지한다.

## 타이포

- Pretendard 산스 단일. 세리프 없음.
- **weight 상한 600.** 800/900은 금지 — 예외는 브랜드 로고 워드마크뿐.
- 화면 제목(`PageTitle`): 22px / 600 / 자간 -0.02em.
- 지도 헤딩: 19px / 600. 보조 문구: caption(11px) / muted.
- 스케일: caption 11 / label 13 / body 15.

## 반경·그림자

- 반경 기준 `--radius: 12px` (sm 8 / md 10 / lg 12 / xl 16).
- 칩·버튼·FAB·아이콘 버튼은 전 형태 pill(rounded-full).
- 카드 12px, 입력 12px, 바텀시트 상단 22px.
- 그림자는 elevation 토큰 e1~e4. e1 = `0 4px 12px rgba(24,24,27,.07)`(카드),
  e3(FAB), e4(플로팅).

## 컴포넌트 형태 스케일

| 부품         | 규격                                                          |
| ------------ | ------------------------------------------------------------- |

| 탭바         | 라벨 10px/500, FAB 48px 잉크 원 + e3, 홈 아이콘=궤도 모티프   |

## 궤도 지도 규격

- 뷰박스 390x560, 중심 (195,285). 링 반경 50/92/134/170.
- 링 = 최근성: 이번 달(≤31일) / 이번 계절(≤92일) / 올해(≤365일) / 그 이전.
  만남 이력 없음은 '그 이전'에서 옅게 쉰다.
- 멀어진 관계: 숨기지 않고 opacity 감쇠 + 노드 양옆 점선 호(quiet arc).
- 태그 필터: 숨기지 않고 흐린다(OR). 매칭 0명이면 초기화 안내.
- 노드 bob·링 등장 애니메이션은 `prefers-reduced-motion`에서 끈다.

## 금지

- 800/900 weight, 세리프, 그라데이션 표면, 네온 포커스.
- 고정 감정 enum 색으로 회귀.
- 데이터 없는 섹션을 꾸며 렌더하는 것.

검수 기준은 `docs/mustpass/orbit-home-gyeol.md`를 따른다.
