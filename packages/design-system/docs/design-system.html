Principles

벽은 사라지고,
유물이 말한다.

Apple이 제품을 박물관 전시품처럼 다루듯, 우리는 사용자의 기억을 그렇게 다룬다. 콘텐츠가 주인공이고 크롬은 조용히 물러난다.

01

단일 액센트 — 아낄수록 강해진다

amber는 주요 CTA, 활성 상태, 포커스 링에만 쓴다. 넓은 배경이나 장식에 쓰지 않는다. Apple의 Action Blue가 하듯, 하나의 색이 시스템 전체의 리듬을 만든다.

색이 적을수록 감정이 또렷해진다
02

면으로 구분 — 그림자보다 표면 색

깊이는 box-shadow가 아니라 white → parchment → pearl 의 표면 사다리로 표현한다. 그림자는 오버레이(대화상자, 시트)에만, 정확히 하나만 존재한다.

03

Pill 버튼 — Apple의 시그니처

주요 액션은 항상 9999px radius. 유틸 버튼만 10px. 터치 타겟은 최소 44px(HIG). 형태만 봐도 "눌러도 된다"는 신호를 준다.

04

여백이 받침대

기록 카드 위아래로 충분한 공기. 콘텐츠 최대 폭 680px — 일기 읽기에 최적화된 시야. 한 화면에 카드를 5개 이상 쌓지 않는다.

05

scale(0.95) — 유일한 micro-interaction

누르는 순간 살짝 줄어드는 것. Apple이 쓰는 단 하나의 피드백. 반복 애니메이션도, 300ms를 넘는 전환도 없다. 조용함이 곧 품격이다.
