01

원칙 — 값이 아니라 규칙

Linear에서 가져온 것은 hex 코드가 아니라 절제의 규칙입니다. 색은 콘텐츠에 살고, 크롬은 조용합니다.

DO

  • 캔버스(#0c0a0f)를 시스템 앵커로 — 미약한 violet 기운은 의도
  • lavender는 브랜드·주요 CTA·포커스·활성 탭에만
  • 표면 사다리 4단계로 위계, 단계 건너뛰지 않기
  • 감정 색은 기록 콘텐츠 안에서만
  • 깊이는 표면 + hairline border로, 그림자 최소화

DON'T

  • lavender를 섹션 배경이나 카드 fill로
  • 두 번째 채도 높은 액센트 도입
  • 대기 그라디언트, 스포트라이트 카드
  • #000000 순수 검정 캔버스
  • 손글씨 폰트를 UI 크롬에

08

거버넌스 — 어디서 왔고, 어디로 가나

레퍼런스

Linear (linear.app) — getdesign.md 명세 기반. 가장 깊은 다크 캔버스, 4단계 표면 사다리, 단일 라벤더 액센트의 절제.

가져온 것 (원리)

색 관계(표면 사다리 + 단일 액센트), 밀도 원칙, 타이포 위계(음의 자간), 깊이 철학(그림자 최소화 + hairline), 캔버스 앵커 사상.

복제하지 않은 것 (법적 경계)

Linear의 로고·상표·전용 서체(Display/Text/Mono)·프로젝트 관리 IA. SaaS 마케팅 레이아웃(pricing 테이블, 3-up 기능 카드).

도메인 확장 (우리가 만든 것)

감정 팔레트 5색, EmotionPicker, DiaryEntry, PersonCard, 편지지 괘선, 세리프 편집 음성, 손글씨 기록 음성. 모두 Linear의 절제 문법 안에서 정의.

다음 단계

사용처 카운트 기반 variant 승격 → 3개월 후 primitive→semantic 전수 대조 재편 → 감정 추이 차트 컴포넌트 → 앱 CSS re-import 1줄 적용.
