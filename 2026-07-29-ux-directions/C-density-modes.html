방향 C · 기록 밀도 모드 프로토타입 — 폰 안 화면을 직접 눌러 볼 수 있어요

MONGLE · UX DIRECTION PROTOTYPE

C. 간결하게 vs 자세하게

기록 밀도를 쉽게 결정하고 기록하는 방법 — "기억하는 세 가지 방법"

01 · 문제

모든 기록이 같은 폼으로 열려요. "더 쓸까?"는 답 없는 고민이고, 사용자는 선택 필드 앞에서 망설여요. 얇은 기록에는 죄책감이, 두꺼운 기록에는 피로가 쌓여요. 현재 폼의 "전부 선택" 설계는 자유가 아니라 결정 부담이에요.

02 · 아이디어

기록 진입의 첫 화면이 폼이 아니라 모드 선택이에요. 세 모드는 같은 폼의 필드 숨기기가 아니라, 각각 따로 설계된 최소 화면이에요.

  • 스탬프 — 만났다는 것만. 사람 확인 → 끝, 2탭. "만났다는 것만으로 충분해요"
  • 엽서 — 감정 하나 + 한 줄, 10초. "감정과 한 줄이면 기억이 깨어나요"
  • 편지 — 왜 · 무엇을 · 사진까지, 현재의 전체 폼. "차분히 적고 싶은 날이 있어요"

각 카드의 정직한 문구가 "이만큼만 해도 괜찮다"고 말해 줘요. 모드 선택은 한 번, 맨 앞에서만. 작성 중에도 "차분히 더 쓰고 싶어요"로 상위 모드로 확장할 수 있어요.

03 · 개선
  • 밀도 결정을 맨 앞으로 꺼내 명시적 선택으로 만들고, 각 선택지를 "괜찮은 것"으로 설계해요.
  • 작성 중 확장: 엽서에서 편지로 넘어갈 때 이미 고른 감정과 한 줄을 그대로 안고 가요.
  • 기록 후 돋우기: 타임라인의 과거 스탬프에 "이 기억을 조금 더 돋울까요?"를 제안해 엽서 · 편지로 자라게 해요. 기존 스탬프 정보는 카드 아래에 남아 위로 쌓여요.
  • 타임라인 밀도 시각화: 스탬프 = 점, 엽서 = 감정 색 점 + 한 줄, 편지 = 전체 카드. 카드 왼쪽 형상 아이콘으로 밀도가 한눈에 보여요.
04 · 상태 — 눌러서 전환

흐름: + 탭 → 사람 → 모드 카드 → 엽서 → 감정 + 한 줄 → 저장 → 타임라인 → (전환) 오래된 스탬프 → 돋우기 → 저장 → 자란 카드.

디자인 언어 "결" — 흰 종이 · 먹색 타입 · 여백 · 따뜻한 악센트. 색은 감정 칩으로만. 손글씨 악센트는 편지 모드 한 줄에만.
