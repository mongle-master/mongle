3계층 토큰 아키텍처

값은 한 방향으로만 흐른다. 상위 계층이 바뀌면 하위 전체가 따라간다.

Tier 1 · Primitives

테마 불변 원시 팔레트 — cream ramp(17), terra ramp(8), emotion(6종), status
:root에 리터럴로 정의. 테마가 바뀌어도 값 불변.

↓ var() 참조

Tier 2 · Semantic

역할 토큰 — --background, --primary, --muted, --emotion-* …
:root/.light와 .dark에서 var()로 Tier 1 참조.
다크/라이트 재매핑의 유일한 소유지.

↓ 직접 소비

Tier 3 · Component

CVA variants + @layer components 클래스.
Tier 2를 직접 소비. 별도 파일 없음. 테마 코드 0줄.

네이밍 규칙

계층마다 하나의 패턴. 전부 kebab-case.

계층패턴예시
Tier 1{hue}-{step}--cream-50, --terra-600, --joy-400
Tier 2{role} / {role}-foreground--background, --primary-foreground, --emotion-joy-bg
Tier 3CVA variant 이름variant="destructive", emotion="calm"

규칙

  • fg/bg 쌍을 반드시 함께 정의 (--emotion-joy ↔ --emotion-joy-bg)
  • 이름 변경은 breaking change
  • 표시형 도메인 컴포넌트는 Tier 2를 직접 소비 가능

Onglip Eunbyeol — 손글씨·일기 본문 (여기서는 Nanum Pen Script로 대용)
오늘은 공원에서 산책을 했다. 날씨가 좋아서 기분이 좋았다. 벤치에 앉아 책을 읽다가 옆에 앉은 할머니와 대화를 나눴다. 그 웃음이 오래 기억에 남을 것 같다.

원칙

  • 손글씨 폰트는 일기 본문·기록 입력에만 — UI 크롬(버튼, 내비, 라벨)에 사용 금지
  • 굵기는 400(본문)과 700·800(제목)만. 중간 굵기 남용 금지
  • 제목은 음의 자간(-0.02em ~ -0.03em), 본문은 기본 자간

법적 경계

Lovable의 로고, 상표, 전용 서체(Camera Plain Variable)와 웹사이트 구조(IA)는 복제하지 않는다. 가져가는 것은 색 관계, 밀도, 위계, 모션의 원리다.
